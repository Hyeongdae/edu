# Plan: 전체 화면 게임 레이아웃

## Goal
로그인 후의 게임 화면이 브라우저 뷰포트 너비와 높이를 채우고, 데스크톱과 모바일에서 헤더, 오디오 설정, HUD, 계단 장면, 안내 카드, 조작 버튼 및 게임 종료 랭킹을 스크롤 없이 한 화면에 표시한다. 브라우저 탭과 주소창을 숨기는 Fullscreen API는 사용하지 않는다.
