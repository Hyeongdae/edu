# Plan: 계단 오르기 게임

## Goal
Vite와 React로 Entra ID 로그인이 필요한 사내용 계단 오르기 게임을 만든다. 데스크톱 D/J 키와 모바일 버튼으로 플레이하고, 실수에 따라 다가오는 추격자, 3회 기회, 30계단마다 활성화되는 30초 더블 점수 이벤트, Entra 사용자별 최고 점수 상위 10개 로컬 랭킹, 경쾌한 BGM과 발소리·넘어짐 효과음을 제공한다. Azure 배포 시 공유 랭킹 저장소를 연결할 수 있도록 점수 저장을 별도 모듈로 둔다.

## Scope and Assumptions
- 새 프로젝트는 TypeScript 기반 Vite + React로 구성한다.
- 인증은 `@azure/msal-browser`와 `@azure/msal-react`를 사용하며, 회사 단일 테넌트 권한만 요청한다. Entra 앱 등록의 Client ID와 Tenant ID는 환경 변수로 제공해야 한다.
- 로컬 랭킹은 브라우저 `localStorage`에 저장한다. 각 계정은 Entra `homeAccountId`로 구분하고, 화면 이름은 Entra 표시 이름으로 보여준다. 이 랭킹은 브라우저 사이에서 공유되지 않는다.
- 직선 구간 길이는 4~6개의 D 이동으로 무작위 생성한다. J는 모퉁이에서 방향을 좌우 반전하며 한 칸 전진한다.
- 추격자는 시작 시 4계단 뒤에서 시작한다. 입력 실수마다 한 칸 가까워지고, 닿으면 기회 하나를 잃은 뒤 같은 계단에서 이어가며 4계단 뒤로 초기화한다. 기회가 0이면 게임이 끝난다.
- 각 성공 이동은 기본 1점이며, 30개의 성공 이동마다 이벤트 게이지가 차고 30초 동안 이동당 2점을 준다. 이벤트가 끝난 뒤 다음 30개의 성공 이동을 센다. 이벤트 타이머는 실제 경과 시간으로 흐른다.
- 사용 허가가 확인된 음원을 `public/audio/`에 포함한다. 로그인 후 메뉴에서 BGM을 시작하며 게임 중 이어 재생하고 게임 종료 시 멈춘다. 자동 재생이 차단되면 사용자가 시작할 수 있는 버튼을 제공한다.
- BGM은 가사 없는 경쾌한 짧은 루프 음악이며, 더블 점수 이벤트 동안 1.25배속으로 재생하고 이벤트 종료 시 기본 속도로 복구한다. BGM과 효과음은 각각 음소거·볼륨 조절이 가능하고 설정은 브라우저에 저장한다.
- 성공적인 D/J 이동마다 돌계단 발소리를 재생한다. 잘못된 입력은 현재 계단에서 0.5초 넘어짐 연출과 묵직한 효과음을 발생시키고, 연출 중 입력을 무시한다. 이때 생명은 줄지 않고 추격자만 가까워진다.
- T01은 필수 Entra 환경변수가 없으면 인증을 우회하지 않고 설정 안내를 보여준다. 로컬 실행을 위해 Entra 단일 테넌트 앱 등록에 `http://localhost:5173` SPA 리디렉션 URI를 등록해야 한다.

## Task Order
1. **T01 Vite React 및 Entra 로그인** — 프로젝트 골격, 환경 변수, 인증 게이트를 만든다.
2. **T02 게임 규칙 엔진** — 입력·점수·이벤트·추격자 상태 전이를 순수 TypeScript로 구현하고 단위 검증한다.
3. **T03 게임 화면 및 조작** — 반응형 만화풍 게임 화면, D/J 및 터치 조작, 이벤트·추격자 표시를 붙인다.
4. **T04 로컬 랭킹 및 게임 종료 연결** — 사용자별 최고 점수 저장, 상위 10위 표시, 판 종료와 재시작 흐름을 완성한다.
5. **T05 라이선스 확인 오디오와 설정** — 허용된 음원·효과음, BGM 속도 변화, 분리된 음량 설정, 브라우저 저장을 연결한다.

## Architecture Notes
- 게임 규칙은 React 컴포넌트에 섞지 않고 `src/game/`의 순수 함수로 둔다. 그래야 잘못된 키 처리, 모퉁이 전환, 기회 소진과 이벤트 점수를 화면 없이 검증할 수 있다.
- MSAL 계정 정보는 로그인 상태에서만 게임과 랭킹 컴포넌트에 전달한다. 클라이언트 측 테넌트 제한은 접근 UX를 제공하지만, Azure 공유 랭킹을 붙일 때는 서버에서도 토큰을 검증해야 한다.
- 게임 경로와 화면은 SVG/CSS 도형으로 구성해 외부 이미지 파일 없이 표시한다. 참고용 생성 시안은 구현 자산으로 포함하지 않는다.
- 오디오 설정은 두 채널(BGM, 효과음)을 분리한다. 구체적인 기본 볼륨은 초기값 0.5로 두며, 저장된 사용자 설정이 있으면 그 값을 우선 적용한다.

## Deferred
- Azure 호스팅과 서버 기반 공유 랭킹은 로컬 게임 완성 후 별도 계획으로 다룬다. 이 저장소에는 기존 Azure 서비스 설정이 없다.
- Entra 앱 등록 및 조직 테넌트 값은 구현 환경에서 사용자가 제공해야 한다. 비밀 값은 프런트엔드에 저장하지 않는다.
- BGM과 효과음의 실제 음원 선택은 T05에서 허용된 사용 범위와 출처를 확인한 뒤 진행한다. 출처, 라이선스, 요구되는 표기를 `public/audio/LICENSES.md`에 기록한다.
