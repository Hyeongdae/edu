# Plan: 계단 오르기 모션과 화면 확대

## Goal
성공적으로 계단을 밟을 때 SVG 캐릭터가 팔·다리를 움직이며 짧게 올라가는 장면을 보여주고, 계단을 약 25% 키우며, 넓은 브라우저에서 전체 게임 레이아웃을 더 크게 표시한다. 기존 밝은 2D 만화풍, 실패 시 넘어짐, 모바일 단일 열 배치, 모션 감소 설정을 유지한다.

## Decisions
- [확정된 결정](../decisions/2026-10-21-stair-climb-animation.md): D/J 성공 이동 애니메이션, 계단 약 25% 확대, 전체 너비 최대 1440px, 참고 시안의 만화풍 SVG.
- 원본 참고 이미지가 저장소에 없으므로 모양을 그대로 복제하지 않고 확정된 밝은 2D 만화 스타일을 따른다.

## Scope and Assumptions
- `GameState`에는 시각 효과를 위한 필드를 추가하지 않는다. `stepsClimbed` 증가를 성공 이동 신호로 이용한다.
- 애니메이션 시간은 약 300ms의 짧은 동작으로 두며, 500ms인 기존 넘어짐/입력 잠금과 분리한다.
- 게임 셸의 최대 너비는 1080px에서 1440px로 변경한다. 720px 이하의 단일 열 배치와 540px 이하 조작 버튼 규칙을 유지한다.
