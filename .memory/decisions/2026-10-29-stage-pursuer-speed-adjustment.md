# Decisions: Stage Pursuer Speed Adjustment

- Date: 2026-10-29
- Status: Confirmed

## D01. 단계별 기본 추격 간격
- **Chosen**: 1단계 500ms, 2단계 400ms, 3단계 350ms, 4단계 300ms, 5단계 280ms마다 추격자가 한 계단 이동한다.
- **Rationale**: 사용자가 새 단계별 속도 값을 지정했다. 기존보다 단계별 속도를 전반적으로 높인다.

## D02. 거리 기반 가속과 넘어짐 중 규칙
- **Chosen**: 간격 15칸에서 시작해 6칸 이하에서 해제되는 100ms 가속 추격, 넘어짐 중 250ms 규칙, 이동 애니메이션은 변경하지 않는다.
- **Rationale**: 요청은 단계별 기본 속도 변경에 한정되며, 기존 별도 규칙은 유지한다.

## D03. 속도 안내 문구
- **Chosen**: 메인 게임 도움말에 단계별 `0.5/0.4/0.35/0.3/0.28초`를, 1단계 단독 하강 실험 도움말에 `0.5초`를 안내한다.
- **Rationale**: 플레이 규칙과 화면 안내를 일치시킨다.
