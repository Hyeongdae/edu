## D01. 단계 종료 체크포인트

- **Chosen — 사용자 선택**: 1~4단계 클리어 직후 체크포인트에서 `계속하기`와 `그만두기`를 선택한다. 자동으로 다음 단계에 진입하지 않는다.
- **Rationale**: 각 단계가 끝날 때 사용자가 도전을 이어갈지 결정할 수 있어야 한다.
- **Derived — 기존 구성에서 정리**: 총 5단계 구성을 유지한다. 5단계 클리어는 최종 결과로 끝내고 존재하지 않는 6단계 진행 버튼을 만들지 않는다.

## D02. 종료와 랭킹 기준

- **Chosen — 사용자 선택**: 그만두거나 실패하면 클리어 단계와 이번 판의 최종 누적 점수를 기록한다. 도전 중인 다음 단계 자체를 클리어로 인정하지 않는다.
- **Chosen — 사용자 선택**: 이전 클리어 이력이 없는 사용자가 1단계 전에 실패하면 `미클리어(0단계)`로 기록한다.
- **Chosen — 기존 확정 규칙**: 단계가 높은 기록 우선, 같은 단계라면 점수가 높은 기록 우선이다. 동점의 기존 달성 시각 보존과 한 판의 단계·점수 쌍을 비교하는 관례를 유지한다.
- **Rationale**: 예를 들어 첫 도전에서 1단계를 클리어하고 종료하거나 2단계에서 실패하면 1단계 기록이다. 재도전에서 이전 진행도를 적용하는 범위는 마지막에 선택한 D06을 따른다.

## D03. 새 판의 점수와 단계별 목표

- **Chosen — 사용자 선택**: 선택한 시작 단계와 관계없이 새 판의 점수는 0점이다. 각 단계에서 400점을 추가로 획득하면 클리어한다.
- **Rationale**: 시작 단계를 선택했다는 이유로 이전 단계 점수를 미리 지급하지 않는다. 이번 판에서 실제 획득한 점수로 비교한다.
- **Derived — 수치 정리**: 1단계부터 연속 진행하면 목표는 초과 득점이 없는 경우 누적 400/800/1200/1600/2000점이다. 3단계부터 새 판을 시작하면 0→400점으로 3단계를 클리어하고, 계속하면 그 점수를 이어서 4단계에 도전한다.
- **Derived — 기존 이동 계약 유지**: 마지막 점프 등으로 목표를 넘으면 실제 획득 점수를 유지한다. 계속할 때는 그 단계 시작 점수에서 400점을 추가로 얻는 목표를 세운다. 점수와 이벤트 게이지는 체크포인트를 거쳐 계속 이어진다.

## D04. 단계 선택과 해금

- **Chosen — 사용자 선택**: 단계 선택창을 추가한다. 2단계까지 클리어한 사용자는 1~2단계를 선택할 수 있다. 아직 클리어하지 않은 다음 3단계로 바로 시작할 수는 없다.
- **Derived — 시작 예외**: 클리어 이력이 0이어도 1단계는 선택할 수 있다. 처음에는 1단계부터 시작한다.
- **Derived — 기존 최고 기록 관례 적용**: 저장한 최고 클리어 단계는 재도전 실패나 낮은 단계 재플레이로 줄어들지 않는다. 기본 선택은 마지막으로 해금한 최고 클리어 단계로 한다.
- **Rationale**: 마지막 클리어 단계부터 재도전할 수 있어야 하며 이미 얻은 단계 선택권을 잃지 않아야 한다.

## D05. 체크포인트에서 시간 정지

- **Chosen — 사용자 선택**: 계속할지 선택하는 동안 단계 제한시간·추격자·보너스 시간을 모두 정지한다. 자동 선택 제한시간은 두지 않는다.
- **Derived — 기존 단계 전환 관례 유지**: 계속하기를 눌러야 다음 단계의 온전한 제한시간과 추격 간격이 시작된다. 점수·경로·장애물 결정·이벤트 진행은 이어지고, 기존 단계 전환처럼 추격자와의 시작 거리는 4칸으로 회복한다.
- **Derived — 입력 경계**: 선택 중 D/J/Space와 화면 이동 버튼이 게임을 진행시키지 않아야 한다. 설정창 정지와 겹쳐도 시간을 이중으로 보정하지 않는다.
- **Rationale**: 사용자가 결정을 고민하는 시간 때문에 도전 조건이나 보너스가 손해 보지 않도록 한다.

## D06. 재도전에 이전 클리어 진행도 적용

- **Chosen — 사용자 최종 선택**: 3단계까지 클리어했던 사용자가 3단계부터 새로 시작해 이번에는 클리어하지 못해도, 그 판은 `3단계 + 이번 판 점수`로 비교한다. 이번 판을 0단계로 되돌리는 안은 선택하지 않았다.
- **Derived — 일관된 기록 기준**: 새 판 시작 시 저장된 최고 클리어 단계를 기록의 기준으로 가져온다. 그 판의 기록 단계는 이전 최고 클리어 단계와 이번 판에서 실제로 새로 클리어한 단계 중 높은 값이다. 플레이 중인 단계와 기록할 단계는 구분한다. 점수는 이전 판과 합산하지 않고 매 판 0점부터 센다.
- **Derived — 최고 기록 보존**: 위 단계·이번 판 점수 쌍이 기존 개인 최고 기록보다 좋아야 교체한다. 이전 최고 기록과 해금 범위는 실패해도 보존한다.
- **Rationale**: 사용자가 재도전에도 이전 진행도를 적용하는 안을 선택했다. 따라서 낮은 단계를 선택한 재플레이에서도 저장된 클리어 진행도를 기준으로 이번 판 점수를 비교할 수 있다.

## D07. 생명 제거와 잡힘

- **Chosen — 사용자 최종 선택**: 생명 제도를 없앤다. 초기 제안인 생명 2개는 취소되었다. 하트·남은 기회·생명 회복 안내를 제거한다.
- **Chosen — 사용자 선택**: 추격자에게 한 번 잡히면 즉시 게임을 종료하고 D02/D06 기준으로 기록한다. 잡힌 뒤 생명을 차감하거나 부활시켜 계속 플레이하지 않는다.
- **Derived — 종료 의미**: 잡힌 시각에 입력·단계 진행·추격 판정을 종료하고 기록을 한 번만 저장한다. 기존 잡힘 연출과 모션 감소 설정은 결과 표현의 기존 관례로 유지하며 부활 대기 시간으로 사용하지 않는다.
- **Rationale**: 생명 없이 추격자에게 잡히는 것이 게임 종료 조건이 된다. 시간 초과도 기존처럼 종료 조건이다.

## D08. 넘어짐 중 0.25초 추격

- **Chosen — 사용자 최신 수정**: 잘못된 방향 입력·상자 충돌·빈 점프 등으로 넘어져 있는 기존 0.5초 동안, 추격자는 단계와 관계없이 0.25초마다 한 칸 올라온다. 앞서 말한 0.3초는 이 값으로 대체한다.
- **Chosen — 사용자 선택**: 일어나면 D09의 해당 단계 일반 추격 간격으로 돌아간다. 해당 단계 끝까지 가속을 유지하지 않는다.
- **Derived — 시간순 판정 유지**: 오입력 자체로 즉시 추격자를 한 칸 이동시키지 않는다. 입력 전에 이미 도래한 추격·종료 시각은 먼저 처리한다. 더 이른 기존 추격 예정 시각을 가속 전환 때문에 뒤로 미루지 않는다. 회복 중 반복 입력은 새 넘어짐이나 가속 연장으로 처리하지 않는다.
- **Derived — 경계 예시**: 다른 더 이른 예정 이동이 없다면 넘어짐 후 0.25초와 0.5초에 추격자가 전진한다. 회복 종료와 겹친 예정 이동도 입력 전에 처리하고, 이후 원래 단계 간격을 적용한다. 가속 중 잡히면 D07에 따라 즉시 종료한다.
- **Rationale**: 넘어졌을 때 추격자가 실제 시간에 따라 더 빠르게 접근하도록 한다.

## D09. 새 판과 계속하기의 구분

- **Derived — 확인한 기존 코드와 사용자 선택에서 정리**: 단계 선택으로 시작하거나 재도전하면 점수 0·새 경로·새 이벤트 게이지·추격자 4칸 뒤에서 시작한다. 선택한 단계의 제한시간·장애물 확률·일반 추격 간격을 처음부터 적용한다. 클리어 해금 이력은 저장된 값을 가져온다.
- **Chosen — 사용자 후속 선택**: 일반 추격 간격을 단계별 800/650/500/400/300ms(0.8/0.65/0.5/0.4/0.3초)로 줄인다. 기존 1000/800/600/500/400ms를 대체한다. 넘어짐 가속은 D08의 250ms로 적용한다.
- **Derived — 유지하는 단계 수치**: 제한시간은 90/75/65/60/50초, 긴 구간 장애물 확률은 10/20/30/40/50%다. 목표 점수는 D03의 단계당 추가 400점이다.
- **Derived — 기존 게임 계약 유지**: 긴 5~9칸과 짧은 1~3칸 패턴, D/J/Space와 모바일 조작, 일반 점프 2점·이벤트 중 4점, 30칸 이벤트, 픽셀 장면·점프 모션·인증·오디오 설정을 기반으로 한다. 같은 시각의 단계 만료는 입력보다 먼저 판정한다.
- **Rationale**: 새로 시작하는 판과 체크포인트에서 이어지는 판을 구분해야 점수·이벤트·시계가 잘못 섞이지 않는다.

## D10. 진행도 저장과 기존 랭킹 초기화

- **Chosen — 사용자 선택**: 기존 랭킹을 초기화하고 모두 1단계부터 새 규칙으로 시작한다. 옛 기록을 별도 보관하는 안은 선택하지 않았다.
- **Derived — 저장 시점**: 실제 단계 클리어 시 최고 클리어 진행도를 계정별로 로컬에 저장해 다음 접속의 단계 선택에 사용한다. 최종 랭킹은 그만두기·잡힘·시간 초과·최종 클리어로 판이 끝날 때 해당 판의 최종 점수와 함께 한 번 저장한다.
- **Derived — 초기화 범위**: 기존 랭킹 형식 v1/v2/v3를 새 규칙 도입 시 정리하고, 새 랭킹은 별도 버전으로 구분한다. 새 형식 기록을 새로고침할 때마다 다시 지우지 않는다. 오디오·인증·다른 로컬 저장 값은 초기화 대상이 아니다. 인터뷰 단계에서는 실제 저장소를 삭제하지 않는다.
- **Rationale**: 기존 기록은 단계당 300점·도달 단계·생명 3개 기준이어서 단계당 400점·클리어 진행도·한 번 잡히면 종료하는 새 기록과 그대로 비교하기 어렵다.
