# Decision: Distance Based Pursuer Catch Up

## Confirmed by user

- 적용 대상은 기존 메인 `/`와 로컬 단독 `/descent-test.html` 모두(선택 3).
- 단계별 기본 추격 간격: 1단계 600ms, 2단계 500ms, 3단계 400ms, 4단계 300ms, 5단계 250ms.
- 실제 계단 간격이 30칸 이상이면 50ms마다 한 계단씩 추격한다. 8~29칸에서는 가속을 유지하고 7칸 이하가 되면 가속을 해제한다.
- 가속 중 넘어져도 50ms 우선(선택 1). 해제 시 아직 넘어져 있으면 기존 250ms 규칙, 회복 후에는 단계별 기본 속도를 따른다. 넘어짐 회복 시간 500ms 유지.
- 단독 실험은 기존 1단계만 제공하므로 기본 600ms와 같은 거리 가속 규칙을 사용한다.
- 목표 점수, 장애물, 경로, 체크포인트, 해금, 기록, 인증, 오디오 설정은 유지한다.

## Engineering decisions

- GameState에 boolean 가속 상태를 두어 진입/해제 경계가 다른 규칙을 표현한다. 점수가 아닌 stepsClimbed - pursuerIndex로 판정한다.
- 절대 시각 기반 엔진을 유지하고 지연된 tick도 동일한 한 계단 이동들을 순서대로 처리한다. 새 가속 진입은 다음 기한을 now+50ms 이내로 당기며 이미 빠른 기한을 늦추지 않는다.
- 화면 갱신은 양쪽 모두 50ms, 가속 이동 애니메이션은 50ms로 맞춘다. 기본 이동 애니메이션 240ms/잡힘 500ms/플레이어 이동 300ms 유지.
- 새 게임·Continue·종료에서 가속을 해제하고 설정/체크포인트 일시정지 시간은 기존 방식대로 보존한다.
