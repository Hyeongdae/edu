# Decisions: 로컬 웹 테스트 모드

- Date: 2026-10-21
- Status: Confirmed

## D01. 브라우저 즉시 테스트 인증 방식
- **Chosen**: `VITE_LOCAL_DEMO_MODE=true`를 직접 설정하고 Vite 개발 서버에서 실행할 때만 로컬 데모 계정으로 인증 화면을 건너뛴다.
- **Rationale**: Entra 앱 등록 정보 없이 현재 게임을 바로 실행할 수 있고, 배포 빌드에서는 실제 Entra 로그인을 계속 요구해야 한다.

## D02. 운영 인증과 개발 모드 격리
- **Chosen**: 데모 모드는 `import.meta.env.DEV`와 명시적인 환경 변수 플래그가 모두 참일 때만 활성화한다. MSAL 설정 누락 오류는 이 경우에만 우회한다.
- **Rationale**: 환경 변수 하나가 배포 환경에 실수로 남아도 프로덕션 빌드에서 인증이 우회되지 않도록 컴파일 시 개발 모드 조건을 적용한다.

## D03. 로컬 데모 계정
- **Chosen**: `local-demo-account` ID와 `로컬 테스트 사용자` 이름을 가진 고정된 가상 계정을 사용한다.
- **Rationale**: 기존 게임 화면과 브라우저별 로컬 랭킹을 그대로 확인할 수 있으며 Entra 사용자 정보를 가장하지 않는다.
