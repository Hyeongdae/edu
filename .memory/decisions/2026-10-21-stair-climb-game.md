# Decisions: 계단 오르기 게임

- Date: 2026-10-21
- Status: Confirmed

## D01. 앱 기반
- **Chosen**: Vite + React SPA로 새 웹앱을 만든다.
- **Rationale**: 저장소에는 기존 앱 코드나 패키지 설정이 없으며, 브라우저에서 실행하는 게임에 맞는 간단한 구성을 원한다.

## D02. 로그인과 이용 범위
- **Chosen**: 플레이 전에 Microsoft Entra ID 로그인을 요구하고, 로컬 개발과 배포 환경 모두에서 로그인을 적용한다. 회사 테넌트 사용자만 접근할 수 있게 한다.
- **Rationale**: 사내 구성원만 게임과 랭킹을 이용해야 한다.

## D03. 화면 스타일
- **Chosen**: 밝은 2D 만화풍으로 만든다. 계단은 좌우로 꺾이는 경로로 보이며, 플레이어·기회·점수·이벤트 게이지를 표시한다.
- **Rationale**: 사용자가 참고용 시안을 확인한 뒤 이 스타일을 선택했다.

## D04. 조작
- **Chosen**: 데스크톱에서는 D 키로 직선 구간을 한 계단 오르고, J 키로 모퉁이에서 방향을 틀며 한 계단 오른다. 모바일에서는 앞으로 화살표와 회전 화살표 두 개를 제공해 각각 D와 J에 대응한다.
- **Rationale**: 단일 전진 키와 단일 회전 키를 사용하며, 모바일에서도 같은 동작을 제공한다.

## D05. 계단 경로
- **Chosen**: 진행 방향은 좌우로 번갈아 꺾인다. 각 직선 구간은 4~6계단 길이로 무작위 생성한다. 모퉁이에서 J 또는 모바일 회전 버튼을 누르면 방향을 바꾸면서 한 계단 오른다.
- **Rationale**: 반복마다 경로가 달라지도록 하되, 너무 자주 꺾이지 않게 한다.

## D06. 실수와 추격자
- **Chosen**: 직선에서 J를 누르거나 모퉁이에서 D를 누르면 실수로 처리한다. 실수하면 플레이어 진행은 유지되고 추격자가 한 계단 가까워진다. 추격자가 플레이어에게 닿으면 기회 하나를 잃고, 플레이어는 현재 계단에서 이어가며 추격자는 시작 거리만큼 뒤로 물러난다.
- **Rationale**: 실수 자체로 기회를 깎지 않고, 추격자에게 따라잡혔을 때만 기회를 잃게 한다. 입력 제한 시간은 두지 않는다.

## D07. 기회와 게임 종료
- **Chosen**: 한 판은 총 3번의 기회로 진행한다. 추격자에게 세 번째로 잡히면 판이 끝난다.
- **Rationale**: 사용자가 총 3번의 기회를 원했다.

## D08. 점수와 이벤트
- **Chosen**: 계단 한 칸을 오를 때 기본 1점을 얻는다. 30계단 연속 진행을 이벤트 게이지에 표시하고, 게이지가 차면 30초 동안 계단당 2점을 준다. 이벤트가 끝나면 게이지를 초기화하고 다음 30계단 진행을 세어 이벤트를 반복한다.
- **Rationale**: 진행 기록과 짧은 보너스 구간을 제공하고, 게이지로 다음 이벤트까지의 진행을 보여준다.

## D09. 랭킹
- **Chosen**: 각 Entra ID 사용자의 최고 점수만 표시하고, 상위 10명을 점수 내림차순으로 보여준다. 이름은 Entra ID 표시 이름을 사용한다.
- **Rationale**: 중복 플레이 기록 대신 사내 구성원별 최고 기록을 비교한다.

## D10. 점수 저장과 배포
- **Chosen**: 첫 버전은 브라우저 로컬 저장소에 점수를 저장한다. 따라서 기록은 브라우저별로만 보인다. 사내 전체 공유 랭킹은 Azure에 배포할 때 공유 저장소를 연결해 확장한다.
- **Rationale**: 먼저 로컬에서 게임을 만들고 이후 배포하기로 했다.

## D11. 배경 음악
- **Chosen**: 가사 없는 경쾌한 아케이드풍 짧은 음악을 사용 허가가 확인된 음원으로 준비하고, 끊김 없이 반복 재생한다. 로그인 후 메뉴에서 재생을 시작해 게임 중에도 이어가며, 게임 종료 시 멈춘다. 브라우저가 자동 재생을 막으면 사용자가 음악을 켤 수 있는 버튼을 보여준다.
- **Rationale**: 빠른 액션 게임 분위기를 지원하면서 사내·상업적 사용 권한을 지키고, 브라우저 자동 재생 제한에도 대응한다.

## D12. 음악 조절
- **Chosen**: 음소거 토글과 볼륨 슬라이더를 제공하고, 선택한 음량과 음소거 상태를 브라우저 로컬 저장소에 기억한다.
- **Rationale**: 사용자가 원하는 청취 수준을 직접 조절하고 다음 방문에도 설정을 유지한다.

## D13. 이벤트 중 음악 속도
- **Chosen**: 30초 더블 점수 이벤트가 활성화된 동안 BGM을 1.25배속으로 재생하고, 이벤트가 끝나면 기본 속도로 되돌린다.
- **Rationale**: 이벤트 구간의 속도감과 긴장감을 음악에도 반영한다.

## D14. 계단 및 실수 효과음
- **Chosen**: 사내·상업적 사용이 허용된 짧은 효과음을 사용한다. 성공적으로 계단을 오를 때마다(직선 D와 모퉁이 J 모두) 가벼운 돌계단 발소리를 재생한다. 잘못된 입력에는 현재 계단에서 0.5초 동안 묵직하게 넘어지는 연출과 별도의 넘어짐 소리를 재생하며, 연출 중 입력은 무시한다. 이 실수 자체로 기회는 잃지 않고 추격자만 가까워진다.
- **Rationale**: 성공과 실수를 서로 다른 소리와 동작으로 알려주고, 짧은 회복 연출 동안 중복 입력으로 추격자 거리가 여러 번 줄어드는 일을 막는다.

## D15. 효과음 조절
- **Chosen**: 효과음의 음소거와 음량을 BGM과 별도로 조절하며, 설정을 브라우저 로컬 저장소에 기억한다.
- **Rationale**: 사용자가 배경 음악과 게임 효과음의 크기를 각각 선택할 수 있게 한다.
